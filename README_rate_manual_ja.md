# 連接符号の符号化率を手動指定するスクリプト

`sweep_concat_rate_manual.sh` は、BBGS外符号と二元Goppa内符号の連接実験で、目標の**連接後の符号化率**を指定して実行するラッパーです。

## 重要な実装上の制約

現在の one-point BBGS + Goppa 経路は、外符号の1シンボルを内符号へ入れる際、内符号の情報ビットを有限体の拡大次数 `m` 個に短縮しています。そのため、この経路で使われる実効内符号次元は

\[
 k_2=m
\]

です。ここで `--syndrome-bits` は二元検査行列の行数 `m*t` をビット数として数えたものです。Goppa復号内部で使う `g(x)^2` を法とする多項式シンドロームの係数表現は別で、最大 `2*m*t` ビット相当になります。したがって、連接後のパラメータは

\[
 N=n_1n_2,\qquad K=k_1k_2=k_1m,
\]

\[
 R=\frac{k_1}{n_1}\frac{m}{n_2}.
\]

Goppa符号そのものの次元が `m` と一致しない場合、スクリプトは実行を拒否します。内符号の実次元を確認せずに、単に `k_2=m` と仮定することはしません。

## 実行例

```bash
chmod +x sweep_concat_rate_manual.sh

# 目標符号化率 5%、エラー100個、100試行
./sweep_concat_rate_manual.sh --rate 0.05 --errors 100 --trials 100

# 目標符号化率を対話入力
./sweep_concat_rate_manual.sh

# シンドローム表現サイズを54 bitに指定（m=6なら t=9）
./sweep_concat_rate_manual.sh --rate 0.05 --syndrome-bits 54 --errors 100 --trials 100

# バースト誤り
./sweep_concat_rate_manual.sh --rate 0.05 --errors 500 --trials 100 --interleave 17 --burst
```

## パラメータ変更

環境変数で曲線・内符号を変更できます。

```bash
M_BITS=6 Q=4 A=1 B=2 INNER_N=60 T=9 \
  ./sweep_concat_rate_manual.sh --rate 0.05 --errors 100 --trials 100
```

GF(256)を使う場合は `M_BITS=8` とし、曲線側の `Q,A,B` が実際に GF(2^8) を構成する組合せである必要があります。曲線構成が未対応なら、スクリプトは limits 取得時に停止します。

## 50%について

現在の内符号短縮方式では、内符号率が `m/n2` です。たとえば既定値 `[n2,k2]=[60,6]` なら内符号率は10%なので、外符号率が100%を超えない限り、連接後に50%にはできません。スクリプトは曲線の有効な `M` 範囲から実現可能な符号化率範囲を計算して表示し、範囲外の目標率では実験を開始しません。

50%を実現するには、内符号の情報次元を `m` に短縮する現行方式自体を変更し、外符号のアルファベットと内符号の全情報次元を整合させる必要があります。このスクリプトはその未実装機能を装ってはいません。
